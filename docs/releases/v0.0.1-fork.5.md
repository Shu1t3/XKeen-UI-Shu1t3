# v0.0.1-fork.5 — защита relay и ограничения входа

Выпуск от 6 октября 2026 года. Изменения относительно v0.0.1-fork.4.

## Исправления

- R05: HTTP/WS relay Mihomo больше не принимает произвольный адрес или порт. TCP-запросы направляются только на 127.0.0.1 и порт `external-controller` из сохранённого `config.yaml`. Некорректный или отсутствующий конфиг закрывает TCP relay; Unix relay сохранён.
- Cookies панели и её Authorization не пересылаются upstream; Set-Cookie upstream не передаётся браузеру. HTTP relay игнорирует системные прокси и не следует перенаправлениям: ответ 3xx возвращается как 502 без Location. Эти ограничения также применены к обращениям тестера маршрутов к API Mihomo.
- R06: ограничение попыток входа учитывает IP TCP-соединения и игнорирует поддельные X-Real-IP/X-Forwarded-For. Попытка резервируется до проверки пароля: параллельные или отменённые запросы не обходят лимит пяти попыток. После последней допущенной неуспешной попытки действует блокировка на 60 секунд.
- Вход и установка пароля используют одну общую операцию Argon2 одновременно. Занятый обработчик возвращает HTTP 429 без накопления очереди; отмена HTTP-запроса не освобождает ограничение до завершения фоновой операции. Память счётчика ограничена 1024 IP с удалением устаревших записей.
- В REVIEW.md закрытые R01, R05, R06 и R34 зачёркнуты, а описания исправлений оставлены обычным текстом. Закрыто 4 из 36 подтверждённых пунктов; 32 остаются открытыми.

## Проверки

- Добавлено 13 регрессионных тестов для R05 и R06, включая реальные HTTP/WS-запросы с инъекциями, запрет перенаправлений, фильтрацию cookies, поддельные IP-заголовки, параллельный вход, истечение блокировки и отмену парольной операции.
- `cargo test` и `cargo test --features local-dev` — по 193 успешных теста; 2 теста с внешними MMDB-файлами штатно пропущены.
- Установка frontend по frozen lockfile, сборка и ESLint без ошибок и предупреждений проверяются перед публикацией.
- Бинарники ARM64, MIPS и MIPSel собираются без `local-dev` и публикуются после успешного завершения всех проверок и сборок в CI.

## Ограничения

Это prerelease. Работа новой версии на реальном роутере ещё не проверена; остальные открытые пункты REVIEW.md сохраняются.

TCP relay поддерживает `external-controller` с адресом 127.0.0.1 или 0.0.0.0 и ненулевым портом. Адрес и порт должны присутствовать в сохранённом конфиге Mihomo.

Настройка доверенных reverse proxy не добавлена по согласованию с пользователем. Все пользователи одного reverse proxy делят лимит его TCP IP. При занятой проверке пароля следует повторить вход позже.
