# v0.0.1-fork.19 — установка основного сервиса XKeen из панели

Изменения относительно v0.0.1-fork.18. Канал выпуска: prerelease.

## Исправления

- Устранена необходимость заранее устанавливать основной сервис XKeen через SSH: в окне «XKeen и ядра» появилась первичная установка стабильного релиза из репозитория jameszeroX/XKeen. Если сервис отсутствует, кнопка запуска открывает окно установки.
- При установке можно выбрать Xray, Mihomo, оба ядра или использовать уже установленные, добавить геобазы и включить автозапуск при загрузке роутера. Установщик добавляет необходимые пакеты Entware; задачи cron и GeoIPSET автоматически не создаются.
- Для новой конфигурации добавлен ввод RCI-токена KeeneticOS 5.2+. Токен сохраняется в `/opt/etc/xkeen/xkeen.json` с правами `0600`; существующая конфигурация не перезаписывается.
- Архив основного сервиса проверяется по SHA-256 из доверенных метаданных GitHub API до распаковки и исполнения. Распаковка ограничена ожидаемыми путями, типами файлов, размером и количеством записей.
- Установка выполняется в фоновой задаче backend и продолжается при закрытии окна или отключении браузера. При повторном открытии доступны состояние, результат и последние 24 КиБ журнала. Повторный запуск и конфликтующие операции управления блокируются.
- Успех определяется кодом возврата и наличием файлов сервиса, конфигурации и выбранных ядер. Ошибки и таймаут выводятся в интерфейсе. В режиме `local-dev` установка на роутер запрещена.
- В README добавлены порядок установки основного сервиса, требования и действия при частичном сбое.

## Проверки

- Frontend: тесты Bun и production-сборка Vite прошли; ESLint без ошибок и предупреждений (`--max-warnings 0`).
- Backend: Clippy без предупреждений в штатном режиме и с `local-dev`; по 329 успешных тестов, по два теста намеренно пропущены. Добавлены проверки аргументов установки, безопасной распаковки, кодов возврата и таймаута процесса.
- Установщики: прошли `test-release-source.sh`, `test-installer-transaction.sh`, `test-self-update.sh` и синтаксическая проверка `setup.sh`.
- Релизный workflow выполняет повторные проверки, собирает бинарники без `local-dev` для arm64-v8a, mips32le и mips32, проверяет `--version` через cross и SHA-256 опубликованных файлов. Публикация выполняется только после успешных проверок и всех трёх сборок.

## Ограничения

Это prerelease. Установка на физическом роутере Keenetic в рамках подготовки выпуска не проверялась. Нужны Entware, права root, поддерживаемая версия KeeneticOS и доступ к GitHub и репозиториям Entware. Без доверенного SHA-256 архива установка не начинается.

Версии новых ядер выбирает upstream-установщик XKeen, включая prerelease. После установки необходимо настроить конфигурацию ядра перед запуском и обновить страницу панели для загрузки новых файлов.

Фоновая задача работает, пока запущен backend панели; его перезапуск сбрасывает состояние задачи. При частичном сбое установленные пакеты и файлы могут остаться: автоматического отката всей системы нет. Существующая или частичная установка XKeen не заменяется; восстановление и обновление основного сервиса выполняются через SSH. Если `xkeen.json` уже существует, RCI-токен нужно сохранить в нём заранее.

Открытые пункты REVIEW.md этим выпуском не объявляются исправленными.
