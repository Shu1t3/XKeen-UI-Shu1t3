# v0.0.1-fork.4 — загрузка обновлений на медленных соединениях

Выпуск от 6 октября 2026 года. Изменения относительно v0.0.1-fork.3.

## Исправления

- Устранён преждевременный обрыв загрузки обновлений после пятисекундной паузы. Отдельный HTTP-клиент загрузчика допускает до 20 секунд на подключение, до 30 секунд на ожидание ответа или очередного блока и до 300 секунд на одну попытку скачивания.
- Эти лимиты применяются к обновлениям панели, Xray, Mihomo и скачиванию yq. Общий клиент API и relay сохраняет прежние ограничения времени.
- При таймауте или обрыве загрузчик переходит к следующему настроенному прокси и начинает загрузку заново. Незавершённые данные не используются как успешно скачанный файл.
- Журнал загрузки теперь указывает источник и подробную причину сетевой ошибки, а также продолжительность таймаута ожидания.

## Проверки

- Добавлены HTTP-тесты с шестисекундной задержкой ответа и шестисекундной паузой между блоками: загрузка завершается успешно.
- Проверен общий таймаут попытки и переход на прокси: частично полученное содержимое отбрасывается, результат содержит только полный файл с прокси.
- `cargo test` и `cargo test --features local-dev` — по 180 успешных тестов; 2 теста с внешними MMDB-файлами штатно пропущены.
- Установка frontend по frozen lockfile, сборка и строгий ESLint без предупреждений проходят перед публикацией.
- Бинарники ARM64, MIPS и MIPSel публикуются после успешной сборки всех архитектур и проверок в CI.

## Ограничения

Это prerelease. Увеличенные таймауты дают больше времени медленному соединению, но не устраняют сетевую блокировку GitHub или недоступность прокси. При переходе между несколькими источниками суммарное ожидание может превышать пять минут.

Работа новой версии на реальном роутере ещё не проверена. Для первого перехода с v0.0.1-fork.3 при прежнем сетевом сбое может понадобиться обновление через консоль: загружающий процесс старой версии ещё использует прежние таймауты. Остальные открытые находки REVIEW.md сохраняются.
