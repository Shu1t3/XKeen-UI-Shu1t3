# v0.0.1-fork.18 — синхронизация с upstream v1.3.5, горячая перезагрузка Mihomo и проверка порта 53

Изменения относительно v0.0.1-fork.17. Канал выпуска: prerelease.

## Исправления

- Выполнена полная синхронизация с upstream-репозиторием (включая версии v1.3.2–v1.3.5) с сохранением всех архитектурных доработок и механизмов безопасности форка.
- Внедрена горячая перезагрузка конфигурации Mihomo через Clash API (`PUT /configs?force=true`) при сохранении изменений. Перезагрузка ядра без разрыва соединений выполняется автоматически, если не затронуты критические параметры (порты, контроллер, секрет) и не активирована опция принудительного закрытия соединений `closeConnsOnApply`.
- Улучшена обработка DNS Keenetic:
  - Добавлено сканирование слушателей 53-го порта роутера с выводом предупреждения в интерфейсе при конфликтах сторонних служб.
  - Определение DNS-серверов провайдера теперь ограничивается только интерфейсами DHCP.
  - Устранено состояние гонки при отключении перехвата DNS в Mihomo: сначала ядро освобождает 53 порт через перезагрузку, после чего снимаются правила RCI.
  - Применение DNS-настроек в RCI переведено на пакетные запросы (batch), что уменьшает задержку и вероятность частичного применения.
- Доработан инспектор и редактор провайдеров правил (Rule Providers):
  - Полноценный просмотр и редактирование провайдеров типа `file` с подсветкой синтаксиса, поиском и валидацией правил на базе CodeMirror.
  - Инспектор провайдеров переведён на унифицированный модуль с поддержкой форматов MRS, YAML и текстовых списков при сохранении защиты от path traversal (R37) и таймаутов конвертации (R38).
  - Добавлена индикация статуса обновления ("ещё не обновлялся") и блокировка ручного обновления для встроенных (`inline`) провайдеров.
  - Оптимизирован скролл диалогов на мобильных устройствах и предзагрузка содержимого для предотвращения скачков интерфейса.
- Улучшен интерфейс селекторов Mihomo:
  - Добавлена кнопка переключения видимости скрытых прокси ("Показать скрытые").
  - Узлы с превышением времени ожидания (timeout) автоматически перемещаются в конец списка.
  - Метаданные исходящих прокси переведены на компактные бейджи; добавлен умный селектор типов.
- Повышена стабильность редактора и настроек:
  - Предотвращена перезапись данных при переключении вкладок в процессе применения конфигураций.
  - Устранено мерцание при смене вкладок в графическом редакторе маршрутов Xray.
  - Блокируются повторные сетевые запросы при нажатии клавиши Enter в диалоге резервных копий.
  - Добавлен дополнительный эндпоинт проверки интернет-соединения в настройках.

## Проверки

- Frontend: 84 успешных теста, production-сборка Vite, ESLint без ошибок и предупреждений (`0 errors, 0 warnings`).
- Backend: Clippy без предупреждений (`--all-targets -- -D warnings`), по 326 успешных тестов в стандартном режиме и с флагом `local-dev` (по два теста намеренно пропущены).
- Установщик: успешно выполнены тесты `test-release-source.sh`, `test-installer-transaction.sh`, `test-self-update.sh` и синтаксическая проверка `setup.sh`.
- Релизный workflow собирает бинарники роутеров без `local-dev` для arm64-v8a, mips32le и mips32, проверяет `--version` через cross и верифицирует SHA256 опубликованных файлов. Публикация выполняется автоматически после успешных проверок и всех трёх сборок.

## Ограничения

Это prerelease. Прямое применение конфигураций на физических роутерах Keenetic локально не эмулировалось. Для горячей перезагрузки Mihomo требуется доступный контроллер Clash API (`external-controller`). Если порт или секрет контроллера изменены в редакторе, выполняется полный перезапуск службы ядра.

Пакетные запросы DNS в RCI используют штатные механизмы KeeneticOS; при нестандартной конфигурации сетевых интерфейсов или сторонних DNS-демонах в Entware может потребоваться ручное освобождение 53-го порта.
