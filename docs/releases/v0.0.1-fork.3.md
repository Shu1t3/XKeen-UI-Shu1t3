# v0.0.1-fork.3 — безопасный выбор ядра

Выпуск от 6 октября 2026 года. Изменения относительно v0.0.1-fork.2.

## Исправления

- **Закрыта command injection при выборе ядра (R01).** Панель принимает только `xray` и `mihomo`. Shell-подстановки, посторонние команды, пути и неизвестные имена отклоняются до остановки процессов или изменения init-скрипта. Мягкий перезапуск использует фиксированные пути бинарников.
- **Восстановлена работа ESLint (R34).** Сборка использует TypeScript 7, а анализатор — совместимый TypeScript 6 API. Исправлены все выявленные ошибки и предупреждение: порядок React hooks, работа с refs, синхронизация состояния, загрузка модальных окон, сохранение причины ошибок и настройка задержки tooltip.
- Добавлено локальное окружение разработки с изолированными путями `.local/opt`, локальным адресом backend и Vite proxy. Операции, требующие роутера, в режиме `local-dev` блокируются.
- Для последующих релизов закреплены обязательные описания исправлений в репозитории и GitHub Releases. Публикация выполняется после строгого lint, сборки frontend и backend-тестов; устаревший Go release workflow удалён.

## Проверки

- `bun install --frozen-lockfile`, `bun run build` и `bunx eslint . --max-warnings 0` — успешно.
- `cargo test` и `cargo test --features local-dev` — по 177 успешных тестов; 2 теста с внешними MMDB-файлами штатно пропущены.
- Добавлены регрессионные тесты R01, включая HTTP-запросы с вредоносными значениями ядра и проверку отсутствия побочных эффектов.
- В локальном браузере проверены шаблоны, бэкапы, геофайлы и диагностика маршрута; ошибок и предупреждений в консоли нет.
- Release workflow собирает бинарники для ARM64, MIPS и MIPSel без `local-dev`; публикация возможна только после успешной сборки всех трёх архитектур.

## Ограничения

Это prerelease. На реальных роутерах этот выпуск ещё не проверен. Остальные открытые находки REVIEW.md сохраняются; закрытие R01 и R34 не означает готовность к массовому корпоративному развёртыванию.
