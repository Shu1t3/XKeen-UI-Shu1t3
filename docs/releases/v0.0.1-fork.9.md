# v0.0.1-fork.9 — отзыв WebSocket-сессий, ограниченный журнал и контроль сборок

Изменения относительно v0.0.1-fork.8. Канал выпуска: prerelease.

## Исправления

- R26: logout, reset и истечение срока сессии закрывают открытые WebSocket журнала и Clash relay. Logout отзывает соединения своей сессии, reset — всех отозванных сессий. Relay закрывает обе стороны и прерывает зависшее подключение к upstream. Перед командами и передачей кадров авторизация проверяется повторно; очистка журнала упорядочена с отзывом сессии. Анонимное соединение, открытое при выключенной auth, закрывается при её включении.
- R27: cleanup frontend отменяет reconnect и ping, снимает handlers до close и блокирует уже поставленные в очередь callbacks. Старое соединение не вмешивается в новое. На backend единая блокировка управляет числом клиентов и watcher журнала; RAII освобождает клиента при раннем выходе, ошибке и отмене задачи. Последний disconnect больше не останавливает watcher нового клиента.
- R28: журнал ограничен последними 1000 строками в памяти и DOM независимо от автопрокрутки. Большой входящий пакет обрезается до создания DOM-узлов. При удалении старых записей сохраняется положение оставшейся строки с учётом переносов и разной высоты; если просматриваемая история вышла за лимит, отображается начало доступных строк. Автопрокрутка продолжает следовать последним записям.
- R33: Cargo.lock хранится в Git; Rust-сборки, metadata, Clippy и tests используют --locked. Закреплены Rust 1.99.0, nightly-2026-10-06, Bun 1.4.2, Node 26.7.0, commit cross, digest образов всех трёх архитектур и SHA release Actions. Ранее восстановленный бинарник cross из кэша не используется. Версия релиза передаётся через переменную сборки, не меняя Cargo.toml/Cargo.lock. Embedded frontend использует deterministic timestamps.
- Проверки и все архитектурные сборки запускаются также на push/PR. Добавлен строгий Clippy без предупреждений в обоих режимах; существующие замечания исправлены без подавлений. Каждый бинарник запускается через runner cross с проверкой версии. Публикация разрешена только отдельным workflow dispatch после успешных проверок и сборок; канал prerelease сохранён. Процесс описан в docs/builds.md.
- В REVIEW.md закрыты R26, R27, R28 и R33. Закрыто 18 из 36 подтверждённых пунктов, 18 остаются открытыми.

## Проверки

- Backend: Clippy всех targets с -D warnings и cargo test --locked в обычном режиме и local-dev; по 252 успешных теста, 2 теста с внешними MMDB-файлами штатно пропущены.
- Frontend: frozen install, 25 успешных тестов, production-сборка и ESLint без ошибок и предупреждений.
- WS-регрессии проверяют отзыв, expiration, сохранение другой сессии при logout, закрытие relay и отмену handshake, ранние выходы и конкурентный lifecycle watcher. Четыре теста буфера проверяют длинный поток, сохранение viewport и большие пакеты. Playwright в браузере подтвердил лимит 1000 строк и отсутствие сдвига оставшейся строки при удалении старых записей.
- CI проверяет shell-транзакции установки/обновления, собирает ARM64, MIPS и MIPSel без local-dev, запускает бинарники с проверкой версии и запрещает изменение Cargo.lock. После публикации сверяет GitHub SHA-256 всех трёх бинарников с результатами сборки.

## Ограничения

Это prerelease. Реальный роутер и полный браузерный UI E2E не проверялись. Smoke-test через runner cross не заменяет проверку запуска сервиса на целевых устройствах.

Закреплены входы dependencies/toolchain/images/actions; побайтовая идентичность независимых пересборок не доказана. Host GitHub runner и инфраструктура остаются внешними.

Журнал хранит только последние 1000 строк: просматриваемые старые записи могут быть вытеснены входящим потоком. Остальные открытые пункты REVIEW.md не исправлены этим выпуском; готовность к массовой корпоративной эксплуатации не заявляется.
