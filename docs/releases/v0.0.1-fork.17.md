# v0.0.1-fork.17 — установка геофайлов из шаблонов и устойчивость обновлений к сетевым сбоям

Изменения относительно v0.0.1-fork.16. Канал выпуска: prerelease.

## Исправления

- В окне шаблонов Xray появилась кнопка «Скачать недостающие файлы». Для выбранного шаблона устанавливаются все отсутствующие базы из набора `zkeen.dat`, `zkeenip.dat`, `geosite_v2fly.dat`. После установки наличие файлов проверяется повторно и автоматически открывается предпросмотр импорта.
- Файлы скачиваются из последних опубликованных релизов соответствующих проектов. Перед установкой проверяются SHA256 из прямого GitHub API и тип GeoSite/GeoIP. Скачивание идёт потоком на диск с ограничением 16 МиБ на файл, таймаутами, повторными попытками и использованием настроенных GitHub Proxy для загрузки самих файлов.
- Все скачанные базы проверяются до записи в рабочие файлы. Каждый файл устанавливается атомарно; исправные существующие базы сохраняются. Закрытие окна не прерывает серверную установку, одновременные установки исключены. Конфигурация не изменяется, ядро не перезапускается.
- Проверка наличия геофайлов теперь учитывает внутренние символические ссылки XKeen, например `zkeenip.dat → geoip_zkeenip.dat`. Это устраняет ложное сообщение об отсутствии уже установленной базы. Внешние и повреждённые ссылки не принимаются.
- Встроенное обновление панели и ядер повторяет запросы метаданных GitHub при ошибках соединения, таймаутах, обрывах ответа и временных HTTP-ошибках. Предусмотрено до пяти попыток с задержками 1, 2, 4 и 8 секунд и общим лимитом три минуты. Учитывается `Retry-After`; причины сетевых ошибок и номера повторов видны в журнале.
- Некорректные метаданные, отсутствие доверенного SHA256 и несовпадение хеша по-прежнему запрещают установку. Проверка HTTPS и источник доверенных метаданных сохранены.

## Проверки

- Frontend: 84 успешных теста, production-сборка Vite, ESLint без ошибок и предупреждений.
- Backend: Clippy без предупреждений и по 320 успешных тестов в стандартном режиме и с `local-dev`; по два теста намеренно пропущены. Проверены временные сетевые ошибки, обрыв ответа, лимит повторов, `Retry-After`, установка нескольких баз, сохранение существующих файлов, отказ при неверном типе и очистка временных файлов.
- Установщик: `test-release-source.sh`, `test-installer-transaction.sh`, `test-self-update.sh` и синтаксическая проверка `setup.sh`.
- В браузере с тестовым API проверен сценарий отсутствующей базы, ошибки загрузки, повторной попытки и перехода к предпросмотру после установки, включая мобильный размер окна.
- Релизный workflow собирает arm64-v8a, mips32le и mips32 без `local-dev`, проверяет `--version` через cross и SHA256 опубликованных файлов. Публикация выполняется после успешных проверок и всех трёх сборок.

## Ограничения

Это prerelease. Установка и применение на физических роутерах пока не проверялись. Для доверенных SHA256 требуется доступ к прямому GitHub API; повторы помогают при временных сбоях, но не устраняют постоянную блокировку сети.

Автоустановка охватывает базы встроенных шаблонов Xray. Произвольные `.dat` устанавливаются вручную, а провайдеры `.mrs`/`.list` Mihomo загружает само ядро при применении конфигурации. Категории внутри баз и совместимость конфигурации проверяет ядро при «Применить».

Запись атомарна для каждого файла отдельно. Если установка следующей базы завершится ошибкой, уже установленные базы остаются; повторная попытка доустановит недостающие. Повторы запросов метаданных добавлены в backend панели; поведение shell-установщиков не меняется.
